🚀 QUICK START (3 STEPS):

1️⃣ GET FIREBASE CREDENTIALS
   ├─ Go to https://console.firebase.google.com
   ├─ Create project "GTL-Store"
   ├─ Get web app credentials from Project Settings
   └─ Copy to js/firebase.js

2️⃣ ENABLE FIREBASE SERVICES
   ├─ Build → Authentication → Enable Email/Password
   ├─ Build → Firestore Database → Create (Test Mode)
   └─ Copy security rules from SETUP.md

3️⃣ SEED PRODUCTS & TEST
   ├─ Open http://localhost:8000/index.html
   ├─ Open DevTools Console (F12)
   ├─ Run: seedProducts()
   └─ Test: Add to cart → View cart → Checkout
